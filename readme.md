# 🦜 Cuckoo Hash Phone Number Management System

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

基于 **SHA-256** 和 **布谷鸟哈希算法** 的电话号码管理系统。通过引入辅助链表解决传统布谷鸟哈希插入过程中的死循环问题，避免扩容重哈希带来的性能损耗。

## 📌 项目简介

本项目是本科毕业论文《密码学中布谷鸟哈希算法的实现与分析》的配套代码实现。

传统布谷鸟哈希在插入冲突时会触发**扩容 + 重哈希**，导致时间和内存开销剧增。本方案通过以下改进提升性能：

- ✅ 基于 SHA-256 设计双哈希函数，保证映射的随机性与安全性
- ✅ 实现带踢出机制的布谷鸟哈希插入/查询/删除
- ✅ 增加**回收链表**：踢出次数超过阈值时存入链表，消除扩容开销
- ✅ 通过平行对照实验验证最优空间倍率

## 🎯 核心成果

| 空间倍率 α | 负载因子 | 死循环率 | 平均插入访问次数 |
|:----------:|:--------:|:--------:|:----------------:|
| 1.0        | 0.8385   | 16.15%   | 86.10            |
| 1.8        | 0.5548   | 0.144%   | 2.70             |
| 2.0+       | ≤0.5     | 0.000%   | ≤1.18            |

> **结论**：当 α ≥ 1.8 时，插入、查询、删除均达到 **O(1) 常数级复杂度**，空间利用率优秀。
